Database Schema & ER Model

The 8 Database Tables (Relational Model)

Table Name Primary Key Foreign Keys Key Attributes & Purpose
1. BRANCH BranchID None BranchName, IFSCCode (Unique), City, State, ContactNumber
2. CUSTOMER CustomerID None FirstName, LastName, DateOfBirth, Gender, Mobile (Unique), Email (Unique), Address, City
3. EMPLOYEE EmployeeID BranchID → BRANCH EmployeeName, Mobile, Designation, Salary (Check > 0), JoiningDate
4. ACCOUNT AccountID BranchID → BRANCH AccountNumber (Unique), AccountType (Saving/Current/Salary), Balance (Check >= 0), Status
5. ACCOUNT_HOLDER (CustomerID, AccountID) CustomerID → CUSTOMER
AccountID → ACCOUNT		 Many-to-Many bridge table connecting customers with their bank accounts. HolderSince, HolderType.
6. TRANSACTION TransactionID AccountID → ACCOUNT TransactionType (DEPOSIT, WITHDRAWAL, TRANSFER_IN, TRANSFER_OUT), Amount, ReferenceNumber, Description
7. LOAN LoanID CustomerID → CUSTOMER
BranchID → BRANCH		 LoanType, LoanAmount, InterestRate, StartDate, TenureMonths, LoanStatus
8. LOAN_PAYMENT PaymentID LoanID → LOAN PaymentDate, Amount, PaymentMode, ReferenceNumber

Entity-Relationship (ER) Connections

 [BRANCH] (1) ─────────────< (M) [EMPLOYEE]      (One branch has many employees)
 [BRANCH] (1) ─────────────< (M) [ACCOUNT]       (One branch maintains many accounts)
 [BRANCH] (1) ─────────────< (M) [LOAN]          (One branch sanctions many loans)

 [CUSTOMER] (M) ──< [ACCOUNT_HOLDER] >── (M) [ACCOUNT]  (Many-to-Many resolved by bridge)
 [ACCOUNT]  (1) ─────────────< (M) [TRANSACTION]        (One account has many transactions)

 [CUSTOMER] (1) ─────────────< (M) [LOAN]               (One customer can take many loans)
 [LOAN]     (1) ─────────────< (M) [LOAN_PAYMENT]       (One loan has many repayment installments)

Stored Procedures

  • sp_transfer_funds: Performs atomic transfer between 2 accounts with START TRANSACTION and COMMIT.
  • sp_deposit_money: Credits balance and inserts transaction.
  • sp_withdraw_money: Checks balance, debits, and logs transaction.

Triggers

  • trg_prevent_negative_balance: Blocks any account balance from falling below ₹0.00.
  • trg_check_loan_completion: Automatically closes loan when repayments ≥ principal.
